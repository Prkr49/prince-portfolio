# Prince Kumar — Portfolio

Personal portfolio website for **Prince Kumar** — B.Tech CSE student at IIIT Bhubaneswar building MERN stack applications and AI-powered tools.

> Open to SDE and Full-Stack Development Internships & New-Grad Roles

## Tech Stack
HTML • CSS • JavaScript • Google Fonts (Space Grotesk, DM Sans, Playfair Display, JetBrains Mono)

## Features
- **Hero** with availability badge and primary actions (view projects, download resume, contact)
- **Profile card** — circular portrait with layered purple/lavender blobs, stats, and profile details
- **Unified Experience timeline** — work experience, hackathon, and education in one continuous timeline
- **Projects** — 4 selected projects with tech tags and source links
- **Skills** — grouped toolkit (languages, frameworks, AI/ML, databases, libraries, dev tools)
- **Contact** form (mail client fallback) and contact details
- **Theme toggle** — dark/light mode with persisted preference
- **Responsive** layout across 1440×900, 1366×768, tablet, and mobile
- **Accessibility** — semantic markup, `aria` attributes, `prefers-reduced-motion` support

## Quick Start
Open `index.html` in a browser, or serve the folder:

```bash
# Python
python -m http.server 8000
# Node
npx serve .
```

## Structure
```
index.html      Page markup
style.css       Design tokens, layouts, and component styles
script.js       Theme toggle, contact form, scroll-spy, reveal animations
photo.png       Portrait asset (transparent-cutout)
resume.pdf      Downloadable resume
```
